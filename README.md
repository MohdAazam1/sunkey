# 🚀 Project Frontend (React + Vite + Tailwind)

A modern e-commerce frontend built using **React, TypeScript, Vite, and Tailwind CSS**. This project includes reusable components, responsive UI, and a scalable structure for production-ready applications.

---

## 📌 Features

- ⚡ Fast build with **Vite**
- 🎨 Styled using **Tailwind CSS**
- 🧩 Reusable React components
- 📱 Fully responsive design
- 🛒 Product listing & cart sidebar
- 📄 Multiple pages (Home, Shop, About, Contact, FAQ)

---

## 📂 Project Structure

```
projectfrontend_/
│── src/
│   ├── components/      # Reusable UI components
│   ├── pages/           # Page components
│   ├── data/            # Static data (products)
│   ├── App.tsx          # Main App component
│   └── main.tsx         # Entry point
│
│── index.html
│── package.json
│── tailwind.config.js
│── vite.config.ts
```

## ⚙️ Installation & Setup

1. Clone the repository:
   git clone https://github.com/your-username/projectfrontend.git  
   cd projectfrontend

2. Install dependencies:
   npm install

3. Run the development server:
   npm run dev

4. Open in browser:
   http://localhost:5173

---

## 📦 Build for Production

npm run build

To preview build:
npm run preview
